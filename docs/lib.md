# توثيق مجلد `lib/`

وصف: يحتوي `lib/` على منطق الخادم والمرافق مثل `prismaClient.js`, استعلامات مخصصة، وأدوات مساعدة.

ماذا يوجد هنا ولماذا:
- `prismaClient.js` : نقطة واحدة لإنشاء وإعادة استخدام اتصال Prisma لمنع تسرب الاتصالات.
- `prismaQueries.js` / `prismaCrud.js` : تجميع الاستعلامات المعقدة بعيدًا عن طبقة الـ API لسهولة الصيانة.

نصيحة:
- اجعل وظائف `lib/` نقية وسهلة الاختبار. اختبرها بمعزل عن إطار الويب عندما أمكن.
