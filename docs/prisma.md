# توثيق مجلد `prisma/`

وصف: يحتوي على `schema.prisma` وهجرات قاعدة البيانات. هذا هو نموذج بيانات التطبيق (Users, Doctors, Chats, Messages...).

ماذا يوجد هنا ولماذا:
- `schema.prisma` : تحديد الموديلات، العلاقات، وأنواع الحقول الأساسية.
- `migrations/` : هجرات تحوي تغييرات نموذجية يتم تطبيقها على قاعدة البيانات.

ممارسات مقترحة:
- اجعل الهجرات صغيرة ومنطقية، واختبرها في بيئة staging قبل الإنتاج.
- لتغييرات خطرة، اتبع استراتيجيات zero-downtime الموضحة في README_AR.md.
