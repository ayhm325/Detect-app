# توثيق مجلد `api/`

وصف: يحتوي `api/` على نقاط النهاية (API routes) التي تعالج طلبات الخادم مثل المصادقة، إدارة الأطباء، والدردشة.

ماذا يوجد هنا ولماذا:
- `api/auth/` : تسجيل الدخول، تسجيل الخروج، تجديد التوكن — فصل مسؤولية المصادقة.
- `api/doctor/` و `api/patient/` : CRUD لبيانات الكيانات الأساسية.
- `api/chat/` : نقاط النهاية المساعدة للدردشة (تحميل الرسائل، جلب المحادثات) بينما يعتمد الوقت الحقيقي على WebSocket.

ملاحظات أمان:
- تحقق من الصلاحيات داخل كل نقطة نهاية.
- لا تعرض بيانات حساسة في الـ responses.
