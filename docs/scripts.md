# توثيق مجلد `scripts/`

وصف: يحتوي على سكربتات مساعدة للتطوير، الصيانة، وإنشاء بيانات تجريبية.

أمثلة مهمة ولماذا:
- `create-dev-token.mjs` : تسريع إنشاء توكنات اختبار.
- `create-test-doctor.js` : إدخال حسابات أطباء تجريبية للـ dev.
- `insert-message.mjs`، `list-chats.mjs` : أدوات لإدارة بيانات الدردشة خارج الواجهة.
- `fix-*`، `backfill-*` : مهام إصلاح بيانات لمرة واحدة عند تغيّر النماذج.

نصيحة تشغيل آمن:
- تأكد من تشغيل هذه السكربتات على بيئات dev أو staging وليس على الإنتاج دون مراجعة.
